# The Reach Screensaver v1.1.0 - release candidate notes

Version 1.1.0 is prepared for owner review. The installer and ZIP are not yet
published. The current public download remains v1.0.0.

## What changed since v1.0.0

- The production itinerary grows from 41 Solar System stops to 64 stops. It
  visits nearby stars, Alpha Centauri A/B, Polaris, Betelgeuse, Antares, Deneb,
  Eta Carinae, R136a1, and WOH G64 in the Large Magellanic Cloud. The authored
  route runs 63 legs out and 63 legs back, reversing at WOH G64 before starting
  another round trip from Earth. The owner estimates WOH G64 at approximately
  157,586 light-years on this route; the exact value awaits release verification.
- Existing journey checkpoints can migrate through the expanded itinerary.
  The voyage retains its saved direction, active leg, odometer, and round-trip
  count when the checkpoint is valid. Invalid checkpoints are kept for recovery
  instead of silently overwritten. Reset Trip removes the journey checkpoint
  on the next fullscreen launch after confirmation, starts at Earth, and clears
  the odometer; settings and downloaded imagery remain.
- The primary display leads a shared panorama. Secondary displays follow its
  camera pose. A composition shift keeps the destination in the primary view
  in a three-monitor layout. The native host passes this shift to all slices.
  Solar System orbit lines remain visible during Reach observation where the
  camera is inside or near those orbits.
- The primary-only HUD adapts distance units across km, AU, and light-years,
  and samples cruise speed from the active leg with improved precision. The
  passive destination information card uses the existing catalogue details.
  These overlays stay off secondary panorama displays.
- The Windows host recognizes v6 checkpoints when confirming Reset Trip. The
  native fullscreen, Settings, and isolated Windows preview paths remain part
  of the package.

## Download and installation

After publication, download the v1.1.0 Windows x64 installer or manual ZIP and
`SHA256SUMS.txt` from the [host release page](https://github.com/NoReturns/TheReachScreensaver/releases).
Check the chosen file against the published SHA-256. The proposed attachment
names are `TheReachScreensaver-1.1.0-Setup.exe` and
`TheReachScreensaver-1.1.0-win-x64.zip`; final names require package review.

The installer installs per user without administrator rights. Close Reach
before upgrading. Installation does not select or enable the screensaver.
The final Setup page offers an unchecked selection action. You can select it
later from the Start Menu shortcut. Windows Screen Saver Settings controls the
idle timeout and resume security option. The manual ZIP must remain complete:
keep `.scr`, `dist`, `windows`, credits, and licenses together, then follow
[`packaging/INSTALL.md`](../../packaging/INSTALL.md). WebView2 Evergreen Runtime
is a separate prerequisite. The installer is unsigned.

Settings shows the visual mode, imagery status, downloads, Reset Trip, privacy,
credits, and source links. Basic uses bundled maps and procedural fallback;
Procedural uses generated surfaces; Enhanced uses verified local images when
available. Optional downloads require user approval and SHA-256 validation.
Normal playback works offline with the complete package and installed runtime.
The native Settings window does not expose visual-mode or countdown selectors;
saved preferences and `reach.ini` control those options.

Fullscreen playback exits on keyboard, click, or deliberate mouse movement.
On one monitor it renders one view. On three monitors it uses adjoining slices
of one voyage, with overlays on the primary display. Windows embedded preview
uses an isolated profile and does not advance the fullscreen checkpoint.
Checkpointing is periodic, so an abrupt exit can resume at an earlier point.

## Known limits and release gate

- This is an authored 64-stop route, not a complete astronomy catalogue.
- Multi-monitor views are not hardware frame-locked. Moving seams can differ
  between frames; bloom may clip at window edges; physical bezel compensation
  is not applied. More displays require more graphics resources.
- Imagery coverage and resolution vary. Some sources have seams, missing polar
  coverage, or non-natural-colour processing.
- Complete 64-stop playback and final one-monitor and three-monitor owner
  visual acceptance are still open. Recent automated and native smoke tests
  support the candidate, but do not close those acceptance gates.
- The v1.1.0 installer and staged package require separate owner acceptance,
  including an upgrade rehearsal. Final checksum publication remains a release
  step. No v1.1.0 installer acceptance is claimed here.
