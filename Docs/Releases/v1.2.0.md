# The Reach Screensaver v1.2.0

Version 1.2.0 expands the passive voyage and keeps the existing Windows host,
offline package, settings, and Reset Trip behavior.

## What changed since v1.1.0

- The itinerary grows from 64 to 71 destinations, with 70 outbound and 70
  inbound travel legs per round trip. The seven additions are Aldebaran, the
  Pleiades, Helix Nebula, Rigel, Orion Nebula, Crab Nebula, and Tarantula Nebula.
  The route still starts at Earth and reverses at WOH G64.
- The Pleiades, Helix Nebula, Orion Nebula, Crab Nebula, and Tarantula Nebula
  use photographic observation views with the accepted faster camera orbit.
- Destination information reports "Light Travel Time (From Camera)".
- V7 journey checkpoints retain the active leg, direction, cycle version,
  odometer, and round-trip count. Earlier V1-V6 checkpoints remain readable;
  an existing V6 journey completes its active cycle before adopting V7 order.
- The Windows host recognizes fresh V7 checkpoints when confirming Reset Trip.
  Fullscreen, Settings, isolated embedded preview, one-monitor presentation,
  and synchronized multi-monitor panorama remain available.

## Download and installation

The intended release assets are `TheReachScreensaver-1.2.0-Setup.exe`,
`TheReachScreensaver-1.2.0-win-x64.zip`, and `SHA256SUMS.txt` on the
[GitHub release page](https://github.com/NoReturns/TheReachScreensaver/releases).
Check the downloaded file against the published SHA-256 before use.

The unsigned installer installs per user. Close Reach before upgrading. It
backs up and verifies the existing installation, then verifies the new payload
before replacement. Journey progress, settings, WebView2 profiles, imagery
caches, and retained deployment backups are stored separately. The final page
offers an unchecked action to select Reach as the Windows screensaver; it
preserves the existing idle timeout, active state, and resume security choice.
The portable ZIP must remain complete, including `.scr`, `dist`, `windows`,
credits, and licenses. WebView2 Evergreen Runtime is a separate prerequisite.
See [installation instructions](../../packaging/INSTALL.md).

The offline package includes the Universe and third-party notices, HYG
CC BY-SA 4.0 attribution, and the required imagery credits. Optional enhanced
imagery remains user initiated and hash verified.

## Known limitations

- The 71-stop route is an authored itinerary, not a complete astronomy catalogue.
- Multi-monitor views are not hardware frame-locked. Moving seams can differ
  between frames; bloom may clip at window edges; physical bezel compensation
  is not applied.
- Checkpointing is periodic, so an abrupt exit may resume from an earlier point.
- Uninterrupted full-route real-time playback and prolonged WebGL endurance
  have not been verified for this release.
