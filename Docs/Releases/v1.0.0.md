# The Reach Screensaver v1.0.0

The first public Windows release of The Reach Screensaver turns an idle desktop into a persistent voyage through the Solar System. It is a free, open-source screensaver for Windows 10 and 11.

## Highlights

- Cinematic travel and observation across 41 authored Solar System destinations, including planets, moons, dwarf planets, Halley's Comet, and historic spacecraft.
- A shared panoramic voyage across multiple monitors, with the countdown and astronomical distance odometer on the primary display.
- Windows screensaver integration with fullscreen playback, embedded preview, and a native Settings window.
- Saved journey progress that resumes across sessions, plus a destination countdown and Reset Trip control.
- Bundled maps and procedural surfaces for offline playback. Optional, user-approved, SHA-256-verified enhanced imagery covers 26 files across 14 destinations.

## Downloads

Download these three attachments from the [GitHub Releases page](https://github.com/NoReturns/TheReachScreensaver/releases):

1. `TheReachScreensaver-1.0.0-Setup-backup-fix.exe` - recommended for most Windows users; installs for the current user.
2. `TheReachScreensaver-1.0.0-win-x64-backup-fix.zip` - complete manual package with installation scripts, local assets, and notices.
3. `SHA256SUMS.txt` - SHA-256 checksums for the installer and ZIP.

The installer is currently unsigned. Windows may show an unknown publisher or SmartScreen warning; review the download and its checksum before deciding whether to run it. Do not disable Windows security protections.

## Requirements

- Windows 10 or Windows 11, x64.
- Microsoft Edge WebView2 Evergreen Runtime, installed separately.
- Graphics hardware capable of running the bundled WebGL experience. Multiple monitors require more graphics resources.

The packages include the .NET runtime. An internet connection is needed only for optional enhanced imagery downloads or to obtain the separate WebView2 runtime.

## Installation

For the installer, close any running Reach windows, run `TheReachScreensaver-1.0.0-Setup-backup-fix.exe`, and complete Setup. It installs under `%LOCALAPPDATA%\Programs\TheReachScreensaver`. The final page offers an unchecked option to select Reach while preserving the existing idle timeout, active state, and resume security setting. A Start Menu shortcut can select Reach later. The per-user `.scr` does not stay in Windows' built-in saver list after another saver is selected.

For the ZIP, extract the complete archive, keep the `.scr` with its companion files, and follow the [Windows installation guide](https://github.com/NoReturns/TheReachScreensaver/blob/main/packaging/INSTALL.md) for the per-user installation and separate selection scripts. Do not copy the `.scr` alone into a Windows directory. The guide also covers upgrade recovery and uninstall behavior.

Uninstall offers an unchecked option to remove retained deployment backups after Reach is removed. It shows the backup folder and size and can open that folder. Keeping the option unchecked preserves the backups. Journey data, downloaded images, settings, profiles, and logs remain in place either way. Pending upgrade recovery blocks backup cleanup.

## Privacy

The application has no analytics or tracking. Journey saves, settings, WebView2 profiles, logs, and downloaded images stay under `%LOCALAPPDATA%\TheReachScreensaver`. Playback uses local resources. Enhanced imagery downloads require your approval and are checked against pinned file sizes and SHA-256 hashes. See [PRIVACY.md](https://github.com/NoReturns/TheReachScreensaver/blob/main/PRIVACY.md) for details, including connections made by image sources and the separately installed WebView2 runtime.

## Known limitations

- The 41-stop route repeats in forward order. Reverse traversal and interstellar travel are not part of v1.0.0.
- Image coverage and resolution vary by destination; some maps include seams, incomplete polar coverage, or non-natural-colour data.
- Multiple displays are not hardware frame-locked. Bloom can clip at window edges, and physical bezel compensation is not applied.
- Journey progress is checkpointed rather than saved every frame, so an abrupt termination can resume from an earlier checkpoint.
- The v1.0.0 installer passed owner acceptance on Windows 11 Home in VM-Chewy. Backup cleanup was disabled there when inspection found an unrecognized historical `pending-upgrade.json.*.previous` artifact. The uninstaller reported the issue and preserved the backups. Actual backup deletion was verified in synthetic tests, not in VM-Chewy.
